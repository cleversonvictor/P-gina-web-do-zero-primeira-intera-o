## World Cup Predictor
  -> O tema do meu projeto, é sobre a copa do mundo, mostrar quem é os mais prováveis a ganhar a copa e os melhores jogadores atualmente!

## Objetivo

Desenvolver um site que analisa dados das seleções para estimar quais têm mais chances de vencer a Copa do Mundo.

## O que o projeto oferece

- Ranking das seleções.
- Probabilidade de cada seleção ser campeã.
- Comparação entre seleções.
- Estatísticas básicas.
- Simulação de partidas.

## Tecnologias

- HTML
- CSS
- JavaScript

## Finalidade

Este projeto foi desenvolvido para praticar desenvolvimento web e aplicar conceitos de estatística e probabilidade utilizando dados do futebol.
